### First-pass validation and limits (historical)

- `npm run lint`: TypeScript check.
- `npm test`: 14 named tests, including broad authenticated API scenarios; exact English/Filipino source evidence, three-author pairs, individual privacy, permissions, concurrent saves, moderation, restart persistence, quota enforcement, controlled stale/malformed model output, rubric ingestion, timeline uncertainty, and tone normalization.
- `npm run test:browser`: headless installed Chrome, isolated data, all six views in both languages at five widths (60 layout states), keyboard dialog behavior, safe HTML rendering, saved reload, retained drafts, real calculator loss, unscored fallback feedback, and visible controlled API failure.
- `npm run build`: production build, with the BMC view loaded separately. Earlier large-chunk/config warnings are removed from the verified build.
- `npm audit --omit=dev`: zero known production-dependency vulnerabilities at the time of this work. Full install still reports five high-severity development-tool findings in the Vite/picomatch dependency chain. The registry did not provide a newer patched picomatch version during this run; no unsafe forced downgrade was applied. The development server binds to loopback by default.

Live Google responses/model availability/accuracy were not tested with a real key. Controlled local model responses test the integration contract, evidence checks, and race handling, not language-model accuracy. The limited safety lexicon is illustrative: substring cues can overflag quoted discussion and can miss paraphrases, obfuscation, contextual harms, or languages outside the fixtures. Teacher reading remains essential.

Before production school use, validate live AI on a larger reviewed Filipino/English dataset, complete school acceptance/privacy/consent processes, configure HTTPS and backup/recovery, and migrate the single-process JSON store if multiple replicas or multiple school tenants are needed. Pricing/usage assumptions require pilot evidence. PDF/DOCX parsing, counselor handoff automation, billing, marketplace transactions, and CSR administration remain explicitly planned capabilities.
